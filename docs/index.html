产品介绍

存图这件事，不该靠右键一张张点

电商详情页的图片分散在主图、轮播、详情长图和背景图里，格式混杂、地址还常被压缩成缩略图。 手动保存既费时又容易漏，整理成统一格式更是额外的体力活。

图片分散，找不到原图

主图、缩略图、背景图混在同一页，缩略图地址还带着 _430x430q90 这类压缩后缀，存下来就糊了。

格式不统一，整理成本高

JPG、WebP、PNG 各来一份，做详情页或选品表格前还得逐张转换、重命名，纯体力活。

一个按钮，全部搞定

提取、过滤、去重、还原原图尺寸、转 PNG、按序号命名——点一次「获取图片」，剩下的交给插件。

核心功能

六个功能，覆盖从提取到落盘

没有多余设置，打开详情页就能用。

一键提取

扫描 <img>、srcset、懒加载属性和 background-image，滚到哪就能提到哪。

智能过滤

按 URL 特征和实际像素双重过滤，logo、图标、占位图、1×1 像素图自动剔除。

集中预览

新标签页网格展示全部图片，带缩略图、真实尺寸和序号名，所见即所得。

自由勾选

全选、反选、单张点选，只要需要的几张，不用为凑数全部下载。

统一 PNG

JPG / WebP 在扩展内用 OffscreenCanvas 重新编码为 PNG，透明底也不会发黑。

批量下载

一次保存到浏览器下载目录，文件名 商品图_001.png 按序号补零，进度实时可见。

安装步骤

四步装好，不需要商店审核

未上架扩展商店，用开发者模式加载即可，全程约一分钟。

  1. 01

    下载并解压插件

    从 GitHub 仓库下载 ZIP，解压到一个固定的文件夹（后续不要删）。

  2. 02

    打开扩展管理页

    地址栏输入 chrome://extensions 并回车。

  3. 03

    开启开发者模式

    打开右上角的「开发者模式」开关。

  4. 04

    加载已解压的扩展程序

    点击「加载已解压的扩展程序」，选择第一步解压出来的文件夹，完成。
